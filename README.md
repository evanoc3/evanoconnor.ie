# evanoconnor.ie

Written with [Astro](https://astro.build/).


## Development

```sh
# Setup
npm install;

# Run locally
npm run dev

# Building for production
npm run build;

# Deploying
docker build -t "evanoconnor.ie" .;
fly deploy --local-only;
```


## External Tools/Services

* [Fly.io](https://fly.io) – hosting
* [Umami.is](https://umami.is) – analytics
