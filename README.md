# evanoconnor.ie

Written with [Astro](https://astro.build/).


## Development

```sh
# Setup
npm install;

# Run locally
npm run dev

# Building for production
npm run build;

# Deploying
docker build -t "evanoconnor.ie" .;
fly deploy --local-only;
```

* [Cloudflare](https://www.cloudflare.com/) – DNS
